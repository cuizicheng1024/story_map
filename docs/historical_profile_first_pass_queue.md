# 历史人物档案首轮全量筛查清单

## 1. 目标

本清单用于执行 `storymap/examples/story` 目录下全部 `527` 份人物档案的首轮知识性问题筛查。

当前状态：

- 已完成对全部 `527` 份人物档案的一次性首轮规则筛查。
- 结果总表见 `docs/historical_profile_first_pass_findings.md`。
- 本清单后续主要用于指导“按风险批次修复”，不再是待启动计划。

当前阶段的核心目标不是逐篇深修，而是先完成以下三件事：

- 全量过目，确认每份档案是否存在明显知识性问题
- 先筛出最容易误导读者的高风险档案池
- 按批次持续修正，避免工作停留在个别样本

## 2. 当前分批规则

- `A 级`：高风险地图类问题，优先处理带 `自动地理编码` 的档案
- `B 级`：高风险引语类问题，优先处理带 `名篇名句` 的档案
- `C 级`：结构性缺项问题，如时间线空白、占位模板、缺少评价字段
- `D 级`：首轮过目后暂未发现明显知识性错误的档案

- 目标：补基础史实、评价依据、争议边界

## 5. 首轮状态标记建议

- `未看`：尚未进行首轮人工过目
- `已看-暂稳`：已过目，暂未发现明显知识性问题
- `已看-待修`：已发现问题，但尚未落盘修改
- `已修-待复核`：已修改，待诊断与一致性复查
- `已修-完成`：已修改并通过复核

## 6. 当前原则

- 先保证“没有明显知识性错误”，再做深修
- 先保证“地图和时间线不误导”，再做措辞优化
- 先做整库排雷，再做个别人物精修
