# 历史人物档案学术审核总报告

## 1. 文档说明

本报告用于汇总 `storymap/examples/story` 目录下历史人物档案的学术审核进展、已发现问题类型、样本修订情况与后续执行规范，作为后续批量校订的工作底稿。

与本报告配套的首轮批量执行清单见：

- `docs/historical_profile_first_pass_queue.md`
- `docs/historical_profile_first_pass_findings.md`

当前审核目标包括但不限于以下字段：

- 人物基本信息
- 生平概述
- 籍贯与出生地
- 生卒年与享年
- 人生足迹地点
- 时间线
- 地点坐标
- 正史或官方评价
- 教材知识点

## 2. 当前盘点结果

截至本轮复核，`storymap/examples/story` 目录下共有 `527` 份人物档案。

抽样检查显示，当前档案整体存在以下特征：

- 人物覆盖面较广，涉及中国古代、近现代与外国人物。
- 档案模板并不统一，至少并存两套以上标题与字段结构。
- 一部分档案带有“自动地理编码”坐标段，存在明显误匹配风险。
- 一部分档案文本叙述较完整，但史实表达不够审慎。
- 一部分档案对“正史评价”“存疑说明”“史学分歧”处理不足。

结合本轮批量扫描，已进一步确认：

- 含 `自动地理编码` 段落的档案共 `59` 份，属于地图知识性错误高风险池。
- 含 `名篇名句` 字段的档案共 `330` 份，是误引、后世概括误作原句的高风险池。
- 当前目录中存在 `张某.md` 这一明显非具体历史人物的占位性文件，需在全量复核中单独处理。

## 2.1 当前任务优先级重排

根据当前工作要求，现阶段审核顺序调整为：

- 第一优先：先对全部 `527` 份人物档案完成一轮“是否存在知识性问题”的全量筛查。
- 第二优先：按高风险类型分批修正明显史实错误、错坐标、时间线缺项与误引。
- 第三优先：在全量过完一遍之后，再进入局部人物的深修、润色与模板统一。

这意味着后续工作重心将从“单个人物深挖”切换为“整库先排雷、后精修”。

## 3. 已发现的主要问题类型

### 3.1 模板不统一

目前档案至少并存以下写法：

- `## 人物档案 / ## 人生足迹地图说明 / ## 生平时间线`
- `## 一、人物档案 / ## 三、人生历程与重要地点 / ## 五、补充说明`

这会带来以下问题：

- 难以批量检查字段缺失情况
- 难以统一展示逻辑
- 不利于后续程序化抽取和自动校验

### 3.2 籍贯、出生地、现代地名混写

常见问题包括：

- 把“籍贯”与“出生地”混为一谈
- 直接把存在争议的出生地写成确定结论
- 古地名、今地名、行政区层级混用

学术风险在于：

- 容易把后世附会当作定论
- 容易造成地图定位偏差
- 容易误导读者理解人物地域身份

### 3.3 以后见之名回套早年经历

常见表现为：

- 把人物早年地方治理经验直接表述为后期制度的“雏形”
- 用后世形成的政治标签、制度名称覆盖当时的具体实践

此类表述虽然便于理解，但不够严谨，容易形成过度线性化叙述。

### 3.4 史实叙述绝对化

常见表现为：

- 将“可能”“多认为”“旧说”“存疑”写成确定结论
- 将过程性历史变化压缩成某一年某一人“尽废”“尽行”
- 对史学界存在分歧的问题未作说明

### 3.5 正史与官方评价字段缺失

不少档案对人物评价的处理存在以下问题：

- 只有现代概括，没有正史依据
- 只有笼统褒贬，没有引述谥号、传论或官方评价
- 对近现代人物缺乏权威公文、讣告、表彰决定等依据

### 3.6 地点坐标高风险错配

地理编码是当前最需要优先处理的问题之一。仓库现有文档已明确记录：

- 国外中文地名易歧义
- 命中错误目标后缺少自动纠偏
- 成功返回不等于定位正确

相关背景见 `docs/geocode_todo.md`。

这意味着：

- 地图点位不能仅凭“已有坐标”视为可靠
- 古地名、模糊地名、跨文化地名需要人工校核
- 涉外人物和古代人物的地图坐标误差风险更高

## 4. 抽样审核结论

本轮已对若干人物档案进行抽样阅读，其中较具代表性的结论如下。

### 4.1 王安石

已完成首轮人工修订，文件：

- `storymap/examples/story/王安石.md`

本轮主要调整内容：

- 修正出生信息的表述方式，区分籍贯与出生地旧说
- 将鄞县经历中的“青苗法雏形”改为更稳妥的地方治理表述
- 将常州经历中的“试图开凿运河”改为更符合史料口径的河道整治表述
- 将“1086 年司马光尽废新法”改为更审慎的“元祐更化中，新法体系随后遭大幅废罢”
- 补入“正史与官方评价”段落，纳入《宋史》评价与谥号信息

### 4.2 李白

已完成首轮人工修订，文件：

- `storymap/examples/story/李白.md`

修订前发现的高风险问题主要包括：

- 出生地表述同时写“碎叶城/绵州昌隆县”，但未明确学界争议层级
- 多个地点坐标明显不符合历史地理常识
- “碎叶城”“长安”“夜郎”等地名的坐标疑似被错误编码为现代中国其他地点
- 个别足迹节点过于笼统，不能准确反映李白安史之乱前后的真实活动空间

本轮主要调整内容：

- 将出生地改为“通常系蜀中青莲乡，亦有碎叶说”的审慎表述
- 保留古今地名映射思路，但把错误坐标改为可落图的人工校正坐标
- 将“中原”“夜郎”一类过粗节点细化为“庐山”“浔阳”“夜郎道中”等更贴近史实的足迹点
- 补入《新唐书》、贺知章评价与唐文宗“三绝”信息

结论：

- `李白.md` 已完成第一轮高风险纠偏
- 后续仍可继续细化其游历段落与教材知识点的史料出处

### 4.3 司马迁

抽样中发现：

- 整体文字质量较高
- 生卒年已标注“存疑”，相对审慎
- 仍可继续增强“正史依据”与“存疑边界”的明确度

结论：

- 属于可在第二批集中精修的档案

- 明确争议点和存疑点

### 第三优先级：模板统一与字段补齐

- 正史与官方评价
- 地点坐标

## 7. 建议采用的学术审核规范

### 7.1 基本原则

- 以正史、权威工具书、可靠学术成果为优先依据
- 对学界有争议的问题，必须标注“存疑”“旧说”“一说”
- 不以小说、戏曲、影视形象代替正史
- 不把后世评价倒置为当时定论

### 7.2 表述原则

- 能确定的写确定，不能确定的明确标注不确定
- 能区分籍贯与出生地的，必须区分
- 能区分古地名与今地名的，必须并列说明
- 能区分史实与文学演绎的，必须明确切开

### 7.3 坐标原则

- 古代地名优先定位到较稳妥的现代行政区或公认遗址范围
- 涉争议地点不强行精确到单点
- 外国人物地点优先使用可靠现代地名，不直接相信中文模糊检索结果
- 对明显错配坐标应先删除或更正，再进入展示环节

### 7.4 评价字段原则

- 古代人物优先补充正史传论、谥号、朝廷评价
- 近现代人物优先补充讣告、表彰决定、官方纪念性评价
- 若无正史专传或无明确官方评价，应如实说明，而非强行拔高

## 8. 建议的批量工作流

建议后续按以下流程持续推进：

1. 先按目录批量筛出“自动地理编码”档案。
2. 抽查并修正明显错配坐标。
3. 再按朝代或主题分组审读人物文本。
4. 对每个人物补齐“正史与官方评价”或“存疑说明”。
5. 完成一批后，统一回查模板与字段完整性。

## 9. 当前结论

本项目中的人物档案已经具备较好的基础框架，但距离“学术严谨、史实准确、可供历史地理研究使用”的目标仍有明显差距。当前最突出的风险不是单个措辞是否优美，而是以下三点：

- 地图坐标中存在可直接误导读者的错配
- 史实叙述中存在“把争议写成定论”的情况
- 评价体系中缺乏统一、可追溯的正史或官方依据

因此，后续工作应坚持“先纠偏，再统一；先高风险字段，再做全面润色”的原则推进。
